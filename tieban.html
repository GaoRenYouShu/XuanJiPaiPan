考时定刻流程详解

铁板神数以刻分入数为纲：四柱定体，刻分定用，六亲考刻定正刻，皇极总数定条文，河洛卦辞证其象，大运流年应其时。

第一步 化数四柱干支各取太玄经数：甲己子午九、乙庚丑未八、丙辛寅申七、丁壬卯酉六、戊癸辰戌五、巳亥单四数。每柱干数加支数为柱数，四柱合计为化数总数。
第二步 刻分每时辰分八刻，每刻十五分钟；刻下再分十五分金，每分金一分钟，全时辰一百二十分金。刻序自初刻至七刻，刻分序为刻序乘十五加分金序，自 0 至 119。
第三步 总数皇极总数 = 四柱化数总数 + 刻分修正数，刻分修正数即刻分序加一。同一时辰一百二十档各得一数、互不重复，故同一时辰之内刻不同、分金不同，则总数各异、条文各异。
第四步 河洛起卦天数为上卦、地数为下卦，各除八取余以先天八卦数配卦（乾一兑二离三震四巽五坎六艮七坤八），得先天卦；皇极总数除六取余定元堂动爻，动而变之得变卦；卦名查六十四卦，卦辞取《易经》原文，另配京房八宫世应与洛书后天数。起卦法载《梅花易数》，梅花法另以卦数总数除六取余定动爻，作参考层。本页取数用太玄数（与上文化数同源），河洛理数页另用纳甲取数并按奇偶分天数地数，两页各依本页所载之法。
第五步 考刻六亲定刻：以三主问答案合成考刻数 = 父母态序×5 + 手足数×3 + 婚姻态序×7，对八取余，在出生时辰八刻内直接定位正刻，答齐即得、必在出生时辰内；子女数为参考问，只定条文口径不参与定位。定位后采用，条文随之重演。
第五步附注 传统考刻法传统"考时定刻"不直接由六亲答案算刻，而是逐刻验条：以出生时辰正刻起数，逐刻排出各刻条文（父母生肖、兄弟数、婚姻等），与求测者已知事实逐一比对，条条相合者定为真刻，不合则进（退）一刻再验，即所谓"进刻退刻"。《铁板神数》有南派重日时干支、北派重月柱时辰之别，两家演算路径不同，但皆以验条为准。本站以考刻数直配八刻，属便用式快速定位，其结论与传统验条法同源而算法不同。
第六步 抽条以皇极总数为纲，按类目取条；父母、兄弟、婚姻、子息四类在考刻采纳后依考刻结论取用同类条文，使条文与六亲相合。
第七步 应运八步大运、未来流年各以干支太玄数与岁次取条文，看十年之体与当年之用。
时刻链路与八字排盘页同序：钟面时刻先按夏令时口径折算（1986 至 1991 年夏令时段钟面折回一小时），再按出生地经度与均时差作太阳时校正（出生地取省市区县经纬真源，也可手动填经度），校正后按子时算法判定日界（晚子时 23 点归次日、早子时 23 点归当日），以最终时刻定四柱；盘面时辰刻分同取最终时刻所归。子时八刻自当日 23:00 顺推至次日 01:00，为一段连续时刻；晚子时八刻同日柱，早子时跨零点日柱随刻而变，故八刻表逐刻各列四柱。考刻定位的正刻恒在出生时辰（钟面）八刻之内；四柱与皇极总数按校正后时刻取。
术语体系

铁板神数条文以皇极总数为纲，同类刻分条文恒定，改刻则条文随之而变，此即考时定刻之义。条文体系分三层：其一为演示条文库，据公开流传铁板类断语整理改编，非秘传全本，非古籍原文，按父母、兄弟、婚姻、子息、田宅、财帛、官禄、性情、健康、寿元十类取条；其二为河洛先天卦，配《易经》卦辞爻辞原文；其三为真典断语，取《三命通会》《渊海子平》《滴天髓》等命经典籍，依四柱十神与命主性别取用，附原典出处。大运流年依子平正统排法。各条文前序号仅便于指称条目。

化数
太玄数干支配数的口诀：甲己子午九、乙庚丑未八、丙辛寅申七、丁壬卯酉六、戊癸辰戌五、巳亥单四数。　太玄经数，铁板类数术最常用的入数元件，每柱干数加支数为柱数。
柱数一柱天干数加地支数，如甲子为 9+9=18。　四柱各有柱数，四柱柱数之和为化数总数。
化数总数四柱太玄数全加起来的和，是皇极总数的主体。　范围 36 至 72（单柱最小 9、最大 18），加刻分修正数后成皇极总数。
河洛理数
天数地数天数为四柱天干太玄数之和，地数为四柱地支太玄数之和。　河洛起卦的两个基数：天数定上卦、地数定下卦。本页取太玄数法，与河洛理数页的纳甲取数法为两套体系，各依本页所载之法。
先天卦天数配上卦、地数配下卦，按乾一兑二离三震四巽五坎六艮七坤八配卦。　邵雍先天数起卦法，载于《梅花易数》。
元堂全卦当权之爻，自下而上数，依皇极总数取之。　考刻改刻则皇极总数变，元堂随之变、爻辞随之变，此即刻改爻改；河洛理数本法以天地数与生时查元堂表，本页元堂取铁板口径，两法并列，详见河洛理数页。
洛书数后天八卦配洛书：坎一、坤二、震三、巽四、乾六、兑七、艮八、离九。　戴九履一、左三右七、二四为肩、六八为足，中五无卦。
卦辞六十四卦卦辞取《易经》原文，爻辞同源。　卦爻辞与全站易学诸页同出一部经文库，六十四卦逐条一致。
京房世应依京房八宫定卦之宫位与世应爻。　六爻纳甲体系的宫世框架，供深入研习者参照。
刻分
八刻一个时辰分八刻，每刻十五分钟，是比时辰更细的时间单位。　子时八刻自当日 23:00 顺推至次日 01:00，为一段连续时刻；晚子时八刻同日柱，早子时跨零点日柱随刻而变。
先天八卦数乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。　刻序依次配八卦数：初刻乾一至七刻坤八，供页面标示刻位。
刻分修正数刻分序加一，使同一时辰一百二十档各得一数、互不重复。　刻分序为刻序乘十五加分金序，自 0 至 119；皇极总数 = 化数总数 + 刻分修正数。
分金一刻十五分金，每分金一分钟；分金序并入刻分序。　全时辰一百二十分金，为考刻最细档；所选分金为钟面档，太阳时开启后盘面分金按校正后分钟取，可能不同。
真太阳时按出生地经度与均时差校正后的太阳钟点。　开启后先校正钟点再归属时辰刻分，以校正后的时辰刻分起盘。
考刻
六亲问卷父母存亡、手足总数、婚姻状况三主问与子女参考问，用已知事实定正刻。　铁板考刻以六亲事实定刻分，答得越真，正刻越明；答卷仅存本机，清除答卷即删除。
考刻数三主问答案合成的定位数：父母态序×5 + 手足数×3 + 婚姻态序×7，对八取余。　考刻数落在 0 至 7，逐一对应出生时辰的八刻；本站以考刻数直配八刻，属便用式快速定位。
正刻考刻数定位的那一刻，必在出生时辰八刻之内，采用后条文随之重演。　子女为参考问，只定条文口径，不参与定位。
传统验条法传统考刻为逐刻验条：逐刻排条文与已知六亲事实比对，条条相合者定为真刻，不合则进退一刻再验。　《铁板神数》南派重日时干支、北派重月柱时辰，两家路径不同，皆以验条为准；本站考刻数法与验条法同源而异算。
总数与条文
皇极总数四柱化数总数加刻分修正数而成，为抽条文之纲。　皇极之名本于邵雍皇极经世之数；范围 37 至 192。
条文抽演按皇极总数取条文，演示条文按数抽演。　同盘同刻条文恒定，改刻即改条文；条文库为演示库，非秘传全本。
条文序号条文前的第 N 号为库内顺序号，仅便于指称条目。　序号供页面引用与查检之用。
六亲取条父母、兄弟、婚姻、子息四类条文按考刻结论取用，口径一致。　六亲相合，条文方验。
真典断语取《三命通会》《渊海子平》《滴天髓》等命经典籍断语，附原典出处。　依四柱十神、五行能量档与命主性别取用，与八字排盘同法同源。
岁运
大运十年一步的运程框架，从月柱顺逆排布。　阳年男、阴年女顺排，阴年男、阳年女逆排，十年一步共八步。
起运出生到第一步大运的折算年数，按节气距离折算。　两种折算口径：时辰折算按整日加时辰档，分钟折算按四千三百二十分折一年，可随流派选用。
流年当年的太岁干支，一年一条文。　流年条文看当年之用，与大运条文合参。
